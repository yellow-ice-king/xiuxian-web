把《修仙搜打撤》加到手机桌面

网页版已经是可安装的 PWA：手机浏览器打开游戏网址后，可以“添加到主屏幕”，之后会像 App 一样从桌面直接进入，全屏游玩。

iPhone（Safari）
1. 打开游戏网址
2. 点底部“分享”按钮
3. 选“添加到主屏幕”
4. 点右上角“添加”
Android（Chrome / Edge）
1. 打开游戏网址
2. 点浏览器右上角菜单“⋯”
3. 选“安装应用 / 添加到主屏幕”
4. 按提示确认

温馨提示：当前临时网址由本机隧道转发，电脑关掉后网址会失效；正式长期玩需要把 web-dist 上传到 Netlify / Vercel / Cloudflare Pages，得到一个固定网址后，再加一次主屏幕即可。
